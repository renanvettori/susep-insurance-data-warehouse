# Data warehouse e ETL com dados públicos da SUSEP

Projeto pessoal e educacional desenvolvido entre 2023 e 2024 para praticar modelagem dimensional, ETL e organização de dados públicos do setor de seguros.

## Objetivo

Construir um data warehouse com dados da SUSEP relacionados a seguro garantia e fiança locatícia, organizando as informações para facilitar consultas e análises posteriores.

## O que foi feito

- análise das fontes públicas e de sua documentação;
- modelagem dimensional em esquema estrela;
- criação de dimensões de empresa, ramo e tempo;
- criação de tabela fato com medidas do setor;
- desenvolvimento de fluxos de extração, transformação e carga;
- tratamento de registros mais recentes e relacionamentos entre dimensões;
- exportação das tabelas para consumo analítico.

## Tecnologias

- SQL Server 2022
- SQL Server Integration Services (SSIS)
- SQL Power Architect
- Visual Studio

## Observações

Este é um projeto histórico de portfólio. A implementação utiliza ferramentas que eram adequadas ao objetivo de estudo na época, como SSIS e SQL Server. O repositório continua relevante para demonstrar fundamentos de ETL, modelagem e data warehousing.

Os dados utilizados são públicos e disponibilizados pela [SUSEP](https://www2.susep.gov.br/menuestatistica/ses/principal.aspx).
